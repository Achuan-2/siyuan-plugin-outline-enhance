# 列表大纲

思源笔记插件，提供悬浮大纲增强、右侧持久大纲增强 Dock 和列表大纲，三种功能可在插件设置中分别开关。大纲默认显示简洁线条，鼠标移入后展开文字；Dock 面板提供常驻的右侧栏目录。

## 大纲增强（悬浮大纲与右侧 Dock）

- **常驻标题块标与折叠按钮**：在插件设置中开启同名开关（默认关闭），编辑区各级标题前会常驻显示 H1–H6 块标和折叠箭头，沿用思源官方块标的定位与主题颜色。点击块标打开原生菜单，点击箭头使用原生折叠操作；鼠标悬停出现官方块标时自动避让。关闭开关或卸载插件后移除控件。
- **右侧大纲增强 Dock**：可在设置中开启「右侧大纲增强 Dock」，在右侧栏注册常驻的大纲增强面板。Dock 支持实时搜索过滤、选择混合列表层级、点击定位、拖动调整结构和右键插入同级；鼠标移到编辑区标题、列表项或普通内容时，会自动定位并高亮对应的大纲条目。
- **拖动排序与调整层级**：桌面端编辑模式下，清空搜索框后可直接拖动 Dock 中的标题或列表项。拖到目标条目的上、下边缘会调整同级顺序，拖到中部会成为目标的子标题或子列表项；子列表项也可拖回上级。标题只能拖到标题，列表项只能拖到列表项，同级列表排序要求列表类型一致。有序列表会自动维持连续编号，操作写入思源事务并支持撤销；预览模式、移动端和嵌入块结果中的条目不提供拖动。
- **悬浮大纲增强**：显示当前文档的标题目录，位于编辑区右侧，随文档切换更新；没有可显示的条目时自动隐藏。
- **右键插入同级**：右键标题条目可「向前插入同级标题」「向后插入同级标题」，后方插入位于当前章节及其子标题内容之后。插入空标题后自动定位以便输入。右键弹出菜单时大纲保持展开，不因鼠标移出而关闭。
- **混合列表目录**：面板顶部和插件设置中的「大纲增强列表层级」下拉框可选择不显示列表，或显示 1–20 层列表，默认不显示并自动保存。列表项按文档顺序归入所属标题，文档开头的列表显示在顶层；列表块的独立层级设置仍优先生效，不提取引述中的列表。此选项不影响独立列表悬浮大纲，混合目录中的列表项也支持定位和右键插入。
- **思源原生大纲树**：使用思源原生 `/api/outline/getDocOutline` 接口，保留完整标题树、标题级别和原生编号，包含折叠及未加载的标题。
- **标题范围**：与原生大纲一致，显示全部标题层级，不受「列表默认大纲层级」限制。
- **点击跳转与高亮**：悬停线条展开标题，点击条目按原生折叠检查与块定位流程跳转；预览模式下优先定位预览标题。Dock 根据编辑区鼠标位置自动定位并高亮标题或列表项，普通内容回退到上方最近的大纲条目；滚动时按当前可见位置更新。可点击「刷新」手动重载。
- **独立开关**：「悬浮大纲增强」「右侧大纲增强 Dock」和「列表大纲」可分别开关，立即生效；关闭不删除原有设置或列表块属性。

实现参考本地思源源码 `D:\Code\siyuan` 中的 `app/src/layout/dock/Outline.ts`、`app/src/util/Tree.ts`、`app/src/util/noRelyPCFunction.ts`、`app/src/protyle/util/editorCommonEvent.ts`、`app/src/protyle/wysiwyg/move.ts`、`app/src/protyle/wysiwyg/transaction.ts` 和 `kernel/model/outline.go`。接口负责标题树生成，插件提供独立悬浮视图和 Dock 视图，不修改思源原生大纲面板。

## 列表大纲

- 当前列表项使用主题强调色高亮线条；高亮跟随鼠标、编辑光标和编辑区滚动，超出显示层级的子项回退到最近的可见父项。

- 右键列表条目可在前方或后方插入同级空列表项，保留无序／有序／任务类型，新任务默认为未完成，插入后自动定位。右键弹出菜单时不因鼠标移出而关闭大纲。
- 悬浮面板优先放在列表正文右侧留白，空间不足时贴编辑区右边缘。

- 支持无序列表、有序列表、任务列表，按列表项嵌套关系生成层级；引述块内的列表项不提取，也不会单独触发大纲。
- 默认仅显示线条，以长短区分层级；鼠标移入大纲后显示文字与层级设置，移出后恢复线条。
- 默认显示前 **3 层**。两种大纲的文字均最多显示一行，按面板可用宽度自动省略，悬停条目可查看完整标题。
- 点击条目定位对应列表项；折叠或尚未加载的条目通过思源原生块定位打开。
- 在插件设置中修改「列表默认大纲层级」（1–20），自动保存。不再提供字数限制设置，旧版字数配置不再生效。
- 在悬浮大纲顶部选择层级，仅影响当前列表；选择「跟随默认」即可清除独立设置。
- 列表处于可视区域内时，大纲持续显示在列表右侧；移出列表块不隐藏，滚动离开可视区域后自动隐藏。
- 支持设置「无子级时不显示列表大纲」，开启后仅包含单层且无子块（如子列表、引述块、代码块、附加段落等）的列表不显示悬浮大纲，包含子块时正常显示。
- 展开列表大纲后支持关键词搜索过滤，实时高亮匹配文字；输入框按 Esc 可一键清空搜索，大纲收起后自动重置搜索状态。
- 鼠标移到大纲上可展开文字与层级设置并进行操作，离开大纲后恢复紧凑线条；按 Esc 也可收起展开的大纲。
- 可视区域内的所有列表均独立显示对应大纲。
- 长列表滚动时，大纲保持在列表可见区域的右上方；大纲条目可独立滚动。

一个最外层列表及其嵌套子列表构成一份大纲，在子项间移动不会反复切换面板。每个条目取该列表项自己的首个文本块，附加段落、列表标记和块属性不生成额外条目。仅鼠标或支持悬停的指针会触发面板，纯触屏交互暂未提供专用入口。

## 数据保存

全局设置保存在插件的 `settings.json` 中。列表的独立层级使用列表块自定义属性 `custom-list-outline-depth`，值为 1–20；未设置或属性无效时跟随全局默认。恢复默认时清空该属性，不改写列表正文或其他块属性。

属性通过思源的 [块属性接口](https://github.com/siyuan-note/siyuan/blob/master/docs/API.zh-CN.md#设置块属性) 保存，可随笔记数据同步。停用插件不会删除已保存的设置。

## 安装与构建

```powershell
pnpm install
pnpm test
pnpm typecheck
pnpm build
```

`pnpm build` 生成 `dist/` 和 `package.zip`，随后自动将 `dist/` 同步到思源工作空间的 `data/plugins/siyuan-plugin-list-outline/`。首次同步后，在思源插件设置中启用「列表大纲」。安装包也可解压到其他工作空间的同名目录。

`pnpm dev` 会监听变化，每次构建完成后自动同步 `dev/`。两种模式均在静态资源写入完成后再同步，覆盖同名产物，保留目标目录的其他文件。

默认目标插件目录为 `D:\Notes\Siyuan\Achuan-2\data\plugins`，可通过环境变量 `SIYUAN_PLUGIN_DIR` 覆盖，或修改 `scripts/make_dev_copy.js`。同步失败会单独输出警告，构建产物仍保留；可运行 `pnpm make_dev_copy dist` 重试生产产物同步，开发产物使用 `pnpm make_dev_copy dev`。

`pnpm typecheck` 检查当前插件入口及其 TypeScript 依赖；模板未使用的示例代码不在此范围内。DOM 测试覆盖层级、截断、标题与列表项拖动事务、块属性保存、异步切换、刷新和清理，不替代思源客户端内的实际交互验证。
